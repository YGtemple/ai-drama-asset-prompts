## 十三、视角与选题：另外两个项目的做法

### 《一会儿》· 叙事视角厘清报告

抽象问题的可执行化。

**问题**：旁白和台词里的「我·你·他·它」到底归谁。
用户两次反馈看似矛盾：
- J02「我叫阿墩，他叫小宇」点过 ok（接受「我是狗」）
- J03「他吃一口、喂我一口」却炸毛

**诊断**：不争论对错，直接指出病根——

> 句子没写清谁在做动作，大脑自动把「我」贴到了
> 画面上正在动的小男孩身上。**这是写法病，不是视角选错了。**

**处方**：全片唯一人称表

| 词 | 固定指代 | 出现场合 |
|---|---|---|
| 我 | 阿墩（狗） | 仅限画外音/内心独白 |
| 他 | 小宇（人） | 狗的画外音里指男孩 |
| 你 | 小宇（人） | 仅限狗对小宇的呼唤句 |
| 它 | 阿墩（狗） | 仅限人类现场台词中称呼狗 |

**论证带三条独立支撑**：参考片实证（《小满》旁白「我」从头到尾是狗，置信度 99%）、叙事必然性（最刀的几句只有狗能说）、返工成本（A 方案 J05–J23 台词不动，B 要重写整个剧本）。

**返工账算到镜头级**：

| 镜头 | 现状 | 动作 |
|---|---|---|
| J01 | 已生成 | 保留，不动 |
| J02 | 已生成 26s | 重渲染 1 条 |
| J04 | **尚未生成** | 按新规范做，**零沉没成本** |
| J05–J23 | 尚未生成 | 台词基本沿用 |

算清楚「哪些已沉没、哪些还能重来」，避免为已生成的镜头勉强维持错视角。

**研究边界写清楚了**：「本轮只读研究 + 写报告文本；未重新生成任何视频/图片，未改动或删除任何成片与资产。」在 AI 批量生产里，这句话防止一次视角讨论引发连锁重渲染。

### 《凝视的接力》· 爆款与案例研究报告

**① 「案例 × 手法」索引矩阵（25 部 × 5 种手法）**

不是罗列，而是矩阵标注每部片子用了哪些手法、哪个是主属：

- ① 同机位/同地点时间对照 ② match cut 匹配剪辑转场
- ③ 现在的自己与童年的自己同框 ④ 年龄递减递推链式结构
- ⑤ POV 凝视/过肩观望/看与被看反转

| # | 案例 | ① | ② | ③ | ④ | ⑤ |
|---|---|---|---|---|---|---|
| 1 | 飞屋环游记 Up | ● | | | ○ | |
| 8 | 父与女 | ● | | ● | ○ | |
| 14 | 人生七年 | | | | ● | |
| 19 | 一一 | | ○ | | ○ | ● |

价值在于**查表**：想做「同机位时间对照」看《飞屋环游记》《父与女》；想做「match cut 转场」看《2001》《阿拉伯的劳伦斯》《云图》。

**② 评估维度里包含「AI 可行性」**

方向②《高处的人》爆款潜力 ★★★★★ 但可行性 ★★★，原因写得很具体：高空脚手架是 AI 高风险画面，易穿模。

创意再好，AI 生成不出来也是零——这个判断很清醒。

**③ 爆款潜力评级带真实数据**

- AI 复活已故父亲：113.9 万赞 / 44.3 万转发
- **转发/赞比 ≈ 39%**
- 《你好，李焕英》内地票房约 54.13 亿元

「转发/赞比」这个指标选得好——点赞代表「好看」，转发代表「想分享给别人」，后者对传播更关键。

**④ 风险提示与深化建议一一配对**

风险：「父亲已故、当年在高处看他」的反转若只用旁白交代会变廉价

建议：父亲身份的揭示**必须靠一次画面匹配转场完成**（挂安全帽 → 童年仰头看见同款帽的父亲），不用台词说破

**⑤ 深化建议是镜头级方案**

- 「黄色安全帽做 3–4 次符号化（父亲的帽 → 传给儿子 → 儿子又把旧书包/新帽递出）」
- 「链条中必须有 1–2 个重情感节点，其余做 2–3 秒快接，形成『长—短—长』的呼吸」

已具体到道具传递顺序与镜头时长节奏。

**⑥ 主动拆自己方案的台**

方向① 评级里写「群像无主角在短视频前 10 秒缺少情感抓手」；风险里写「无主角=无强代入，容易『高级但不转发』」。

正是因为看到了这个弱点，才有了方向②的诞生。

## 十四、可复用的做法清单

| 做法 | 解决的问题 |
|---|---|
| 主锚定 + 跨龄重复骨相特征 | AI 换脸 |
| 固定 seed + 风格化/怪异度/多样性全压低 | 跨镜不一致 |
| 空间站位 + 机位（Plate-A/B/C/D）锁定 | 分镜对不上 |
| ASCII 俯视图 + 轴线规则 | 越轴、空间错乱 |
| 道具连续性表追踪每状态跳变 | 道具凭空变形 |
| 「不得重建房间」重复声明 | 同一场景生成不同样 |
| 材质排他句（「不是大理石」） | 静物被生成成石头 |
| 「无人物、无人手」 | 静物图多出手 |
| 配音指令四段式 | 角色声音跨镜不一致 |
| 镜头时长按情绪权重分配 | 节奏平均无层次 |
| 全片唯一人称表 | 视角歧义引发返工 |
| 返工账算到镜头级 | 沉没成本算不清 |
| 案例 × 手法矩阵 | 找参考片没头绪 |
| 评估含 AI 可行性维度 | 创意好但生成不出来 |
| 风险与建议一一配对 | 建议泛泛不可执行 |
| 主动拆自己方案的台 | 只自夸不客观 |
| 版本修正记录 | 同一个坑反复踩 |
| 废片归档 + 标注原因 | 不知道什么方案行不通 |
