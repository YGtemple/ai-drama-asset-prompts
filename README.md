# ai-drama-asset-prompts · AI 真人短剧资产提示词工程

> 一句话简介：真人写实短剧的资产提示词方法论——跨龄面容一致性、四宫格锚定、站位机位锁定、废片归档与版本修正。

素材来自短剧项目《反话》的真实资产包（角色 10 · 场景 10 · 道具 4），以及另两个项目的同类实践。

## 一、核心问题：AI 生成资产的三大翻车点

做 AI 真人短剧，资产层要解决三件事：

1. **同一角色跨龄跨镜不能换脸** —— 生成 7 岁 / 24 岁 / 灵魂状态的陈默，脸必须是同一个人
2. **同一角色跨集要一致** —— 16 个分镜组里江晓不能每次生成不同
3. **道具状态变化要可控** —— 同一块橡皮要能生成「崭新 / 半旧 / 磨剩」三态

这份资产包给出的是可复制的解法。

## 二、跨龄面容一致性：主锚定 + 控制维度

### 角色卡按年龄段拆分，但共享「面容锚点」

陈默有 B1（24 岁，主锚定）、B2（7 岁）、B3（13 岁）三张卡。**每张卡都重复描述同一套面部特征**：

```
B1 24岁：窄中带方的脸型、下颌线利落、双眼皮、浓黑眉、
        高直鼻梁、薄唇、颧骨不高、肤色冷白偏暖
B2 7岁： 窄中带方的小脸、下颌线初显、双眼皮、浓黑淡眉、
        高直小鼻梁、薄唇、肤色冷白偏暖、缺一颗上门牙、乳牙期
B3 13岁：窄中带方脸、双眼皮、浓黑眉、高直鼻、薄唇、
        肤色冷白偏暖、青涩、面部线条未长开
```

年龄段只改**皮肤与轮廓的成熟度**，不改骨相特征。这样 AI 生成时有明确的锚点可循。

### 每张卡末尾都带「控制维度」

```
▶ 控制维度：风格化〔低，面容须跨镜复现〕｜怪异度〔低〕｜多样性〔低，固定 seed〕
```

这一行是**整套方法的核心**。文档给出的理由：

> 本片靠同一张面容跨龄、跨镜复现，任何高 stylize / weird / chaos 都会换脸或破坏材质可信度。

- `风格化=低` —— 高风格化会重绘五官
- `怪异度=0` —— 怪异度会影响面部结构合理性
- `多样性=低 + 固定 seed` —— 高多样性每次生成结果都不一样，跨镜必然崩

只有「彼岸」场景（A10）允许风格化「低中」（轻微梦幻柔光），其余全部压到最低。

## 三、场景卡：站位与机位锁定

场景资产不只是「画一张好看的图」，还要**锁死空间关系**，否则分镜阶段镜头对不上。

### 小家餐厅的机位锁定

```
南墙大窗暖光向北；餐桌东西向长轴、贴窗北沿。
北长凳＝江晓固定位、面朝南；南长凳（窗下）＝他的位、碗筷永摆。

Plate-A 主机位在餐桌东侧朝西：江晓恒画面右、南椅/窗恒画面左，
魂入画恒从窗侧/画面左。
派生 Plate-B（她右肩后 OTS 朝南椅/窗）、
Plate-C（窗北侧朝南拍她正面，魂视角）、
Plate-D（俯拍桌面/道具）。
```

这段把「谁坐哪、镜头从哪拍、谁在画面哪侧」全部固定。派生机位（A/B/C/D）也在一开始就规划好，避免拍到中途才发现缺某个角度。

卧室同样锁定：

```
床贴东墙、床头朝北；床头柜在东北角；床尾西南放椅＝她凝望处；
真陈默俯在床头右侧。
```

**空间关系的确定性 > 单张图的美观度**。分镜阶段要靠这些坐标推镜头位。

## 四、道具卡：状态拆分 + 材质排他

### 橡皮的三状态

```
三状态：①崭新完整白色软橡胶橡皮、棱角分明；
       ②用掉一半的半旧白橡皮、边角圆润、擦拭面沾浅灰铅笔印；
       ③磨剩拇指大的橡皮头、圆钝、整体发白、擦拭端面黑灰。
```

一块橡皮的三态在一张图里并排摆放。生成一次拿到三个状态，后续分镜直接引用。

### 材质排他条款

每张道具卡都带一句**否定式约束**：

```
橡皮明确为软橡胶、哑光、柔软、边角圆润，
不是石头、不是大理石、无石材纹理。
```

这是针对 AI 的已知翻车点——「白色块状物」很容易被生成成大理石或玉石。加一句排除，比反复重抽省时间。

保温桶和碗筷都加了「**纯静物四视图、无人物、无人手**」：

```
四视图、无人物、无人手：左正面盖好、中侧面、
右一只盖子打开、盖子取下竖立放在桶旁台面、可见内胆分格，
下为提手焊接细节特写。
```

**排除手**很重要——AI 默认会给人画一双手拿着，静物图就废了。

## 五、版本修正机制：把翻车点记录下来

这是整套资产包最值得学的地方。文档开头有一段「**本版相对 v1 的关键修正**」：

```
- 陈默为双眼皮（v1 误写单眼皮，作废）；
  成年 B1 实物穿黑色圆领针织毛衣（v1 误写米白，作废）＋深灰长裤。
- A7 改为「白天·十字路口·婚庆店」
  （v1 的"无灯路口·傍晚/夜"作废）。
- B9/B10 两位母亲、A1–A10 全部场景、C1–C4 全部道具均为重做新资产，
  已经用户逐张确认。
```

这段话的价值在于：**它把「提示词写错导致生成翻车」这件事显式记录下来了**。

- v1 写「单眼皮」，实际生成出来是双眼皮 → 改口径
- v1 写「米白针织衫」，实物是黑色 → 以实物为准
- A7 的时间光线设定整体作废 → 重做

如果不做这个记录，下一版提示词还会犯同样的错，而且没人知道当初为什么要这么写。

## 六、视频生成规则（资产 → 视频的衔接）

文档末尾给了完整的视频生成规则：

```
每个片段首图＝对应机位底图（不 @），
随后逐角色挂角色锚定图（逐人 @图片、一人一图、
强制图片参考不纯文字生成人物）；
生视频前完整展示提示词；
交付前「下载→整段解码校验→转 H.264(yuv420p)+AAC+faststart
（CRF≈16–18，不缩放/不降帧/不调色）→抽帧质检→
连同提示词交付，用户认可才下一个」；
废片归档 _废片 标注原因；
全部合格后按 G01–G16 硬拼接，两张黑底白字时间卡落位。
```

有三个要点：

1. **首图用机位底图，角色用锚定图分开 @** —— 混在一起会串味
2. **「用户认可才下一个」** —— 逐段确认，不批量生成
3. **废片归档并标注原因** —— 与项目 README 里的 `废片/` 目录策略一致

## 七、全局视觉铁律

跨段落的硬约束，集中写在文档开头：

```
生前段：Fuji Eterna 胶片暖棕，色温 2700–3200K，细腻胶片颗粒、微弱暖光晕。
车祸段（白天）：阳光很好、硬阴影；车冲来以太阳眩光过曝光成白、
        画外刹车闷响，撞后短暂失色＋耳鸣；
        不直拍撞击、无血腥、无尸体特写。
鬼魂段：暖房间（暖黄）＋魂边冷蓝辉 6500K 对撞；
        冷蓝辉是唯一无实体光源，只勾身体边缘、不投光、不生光束；
        室内禁体积雾。
成片：无字幕、无 BGM，真实环境音写足保留；
      禁用 TTS，台词/旁白全部写进视频提示词由模型直接发声。
```

「冷蓝辉是唯一无实体光源，只勾身体边缘、不投光、不生光束」——这种程度的细节约束，是试出来的。

固定声线也写进提示词（如「陈默：清瘦青年男声、音区偏低微哑、语速平、尾音硬」），并注明「非 TTS」，即交给视频生成模型直接发声。

## 八、可复用的做法清单

| 做法 | 解决的问题 |
|---|---|
| 主锚定 + 跨龄重复面部特征 | AI 换脸 |
| 固定 seed + 风格化/怪异度/多样性全压低 | 跨镜不一致 |
| 空间站位 + 机位（Plate-A/B/C/D）锁定 | 分镜对不上 |
| 道具多状态同图并排 | 状态变化难控 |
| 材质排他句（「不是大理石」） | 静物被生成成石头 |
| 「无人物、无人手」 | 静物图多出手 |
| 版本修正记录 | 同一个坑反复踩 |
| 废片归档 + 标注原因 | 不知道什么方案行不通 |
