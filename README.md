## 八、分镜层的写法（给 AI 消费）

分镜是剧本与视频生成之间的中间层。核心约束：**每一镜都要写全摄影参数**。

### ① 镜头描述的四个必填参数

```
镜头1：6s 全景转中景，平视，32mm，轻推。
镜头3：6s 中景，侧逆光，35mm，固定。
镜头4：3s 特写，俯拍本面，85mm/微距，固定。
```

**时长 · 景别 · 机位角度 · 焦段 + 运镜**。

焦段选择有明确意图：

| 焦段 | 用途 |
|---|---|
| 32mm | 全景，交代空间关系 |
| 50mm | 近景，人物互动 |
| 85mm | 特写，情绪放大 |
| 微距 | 道具细节 |

### ② 配音指令的四段式结构

```
【配音指令：陈默7｜稚嫩童声脆
  ｜状态（念书/似懂非懂）
  ｜语气特点（小音量/语速慢/一字一顿）：
  书上说……人一直干活，就会变老；】
```

四段拆解：

| 字段 | 作用 |
|---|---|
| 音色标识 | 角色名 + 年龄（如「陈默7」）|
| 音色特征 | 音质描述（如「稚嫩童声脆」）|
| 情绪状态 | 当前情绪（如「念书/似懂非懂」）|
| 语气参数 | 音量/语速/尾音（如「小音量/语速慢/一字一顿」）|

**关键设计**：音色特征字段在同一角色的所有镜头里**保持不变**，变的只是状态与语气参数。

对比同一角色的三镜：

```
陈默7｜稚嫩童声脆｜状态（念书/似懂非懂）｜小音量/语速慢/一字一顿
陈默7｜稚嫩童声｜状态（害怕/冲口）｜大音量/语速快/尾音硬
陈默7｜稚嫩童声｜状态（嘴硬/手忙脚乱/肯借）｜大音量/语速快/尾音硬得像质问
```

音色基底统一，情绪与语气变化可控。这就是跨镜头角色声音一致的技术手段。

### ③ 镜头时长按情绪权重分配

不是均分。某组 7 个镜头的时长是 `4/4/3/3/3/5/4`：

- 情绪平淡的镜头（同学转头、拿起橡皮）→ **3 秒**
- 对白密集的镜头（陈默嘴硬连说两句）→ **4 秒**
- 情绪关键镜头（江晓替他正名）→ **5 秒**

### ④ 「不得重建房间」写进每组正文

```
场景：陈默家（背景、机位、门窗、挂钟严格不变，
不得重建房间，仅人物动作变化）
```

这条约束在每个分镜组里重复出现。原因很直接——AI 生成时不强调，会把同一个房间生成成不同样子：挂钟位置变了、窗户数量变了、墙色变了。

### ⑤ 两段式结构（输入头 / 渲染正文）

```
_::~OUTPUT_START::~_
场景：…【场景参考·X，首位不@】
角色：陈默7岁【@图片1】；母亲【@图片2】
物品：…【@图片3】
_::~FIELD::~_
（渲染正文：逐镜描述）
```

输入头是**结构化的素材引用清单**，正文是**自然语言画面描述**。AI 先读引用建立素材绑定，再读正文生成画面。

### ⑥ 承接写在组尾

```
衔接（至下一组）：硬切连贯——同场景，
他憋到极致→冲口而出，不加片。
```

明确三件事：从哪接、用什么转场、衔接点在哪。

## 九、道具连续性表：追踪每个状态跳变

长片最容易崩的地方之一是道具状态。文档里用一张表锁死：

| 道具 | 关键走向（不可跳变） |
|---|---|
| **白橡皮** | 场2 半旧借出 → 场4 崭新相赠、与旧橡皮并放铁皮盒 → 场5 压保温桶 → 场6 落地滚上白天斑马线 → 场8–9 盒中橡皮逐年增多 → 场10 临终只剩「橡皮头」；彼岸他递来**崭新**橡皮 |
| 铁皮盒 | 场4 首现（2 块）→ 场9 满盒（数十年）→ 场10 临终后不再出现 |
| 保温桶 | 场5 盛粥、深夜放新橡皮 |
| 两副碗筷 | 场7 起永远摆两副；**南椅永远摆碗筷**，她只对南椅说话 |
| 婚庆宣传册 | 场6 开场陈默手里，推人时脱手 |

一条道具线跨 10 场、经历借出/赠送/并放/压制/落地/累积/磨剩/重置八个状态。AI 生成最容易出问题的地方就是上一镜还在口袋里、下一镜就变新了。

## 十、空间关系用 ASCII 俯视图锁死

```
北 N
┌─────────────────────────────────────┐
│ 入户门(NW)          厨房·灶台(NE)      │
│                                       │
│   [江晓·北长凳]  她固定坐，面朝 南       │
│     ┌───────────────────────────┐     │
│     │     餐 桌（东西向长轴）       │     │
│     └───────────────────────────┘     │
│   [他的·南长凳(窗下)] 永远摆碗筷         │
│                                       │
│   ▓▓▓▓▓ 南 窗（暖光向北照）▓▓▓▓▓       │
└─────────────────────────────────────┘
南 S
```

「南窗（暖光向北照）」这一行同时锁定了方位**和**光线方向。空间关系用图比用文字描述准确得多。

配套的机位表：

| 底图 | 机位 | 拍到什么 |
|---|---|---|
| A（主）| 东侧朝西，35mm，固定 | 双人位：江晓 R、南椅/窗 L，建立空间 |
| B | 她右肩后侧朝南椅（OTS），50–85mm | 她肩 R 前景、空南椅＋窗 L（她「对他说话」主力） |
| C | 南窗北侧朝北（魂的视角），50mm | 她正面、她「替他回话」时的脸 |
| D | 俯拍桌面，85mm/微距 | 两副碗筷、两碗饭、铁皮盒/橡皮等道具 |

**轴线规则**：「以两长凳 N–S 为关系轴；她与『空位』的对话机位统一在房间东半侧，不越轴」。这是电影摄影的基本功——AI 单镜头内不会越轴，但跨镜头拼接时机位没约束，成片会明显穿帮。

## 十一、分段视觉参数表

用胶片型号 + 色温 + 颗粒 + 光晕四个参数控制调性，比笼统的「暖色调电影感」精确得多：

| 段落 | 场 | film_stock | 色温 | 特征 |
|---|---|---|---|---|
| A 生前段 | 1–5 | Fuji Eterna | 2700–3200K | 暖棕、低饱和、细腻颗粒 |
| B 车祸段 | 6 | Eterna 白天延续 | ~5500K | 硬阴影；**车冲来瞬间太阳眩光过曝成白**，撞后色彩短暂抽离、声音压成耳鸣；撞击不直拍 |
| C 鬼魂段 | 7–9 | Eterna | 房间 3000K × 魂边 6500K | 暖房间 × 冷蓝辉对撞 |
| D 彼岸段 | 10 | Kodachrome | 暖金 | 明亮通透；**冷蓝辉消失、手变实变暖** |

### 鬼魂段的光线铁律（文档标了「最高优先级」）

```
- 冷蓝辉光是唯一的「无实体光源」，
  只勾身体/手臂/侧脸的边缘轮廓，
  不在墙上投光、不照亮地面、不产生光束；
- 房间内禁止体积雾/可见光束/丁达尔；
  纵深靠「南窗光＋曝光分离」与
  「前景遮挡（门框、椅背、碗沿）」建立；
- 她始终在暖光里，他始终半在暖光外、边缘带冷蓝
  —— 冷暖交界即「两个世界」的边界。
```

最后一句把光线约束上升成了**叙事隐喻**。这不是技术描述，是视觉语言。

## 十二、可复用的做法清单

| 做法 | 解决的问题 |
|---|---|
| 主锚定 + 跨龄重复骨相特征 | AI 换脸 |
| 固定 seed + 风格化/怪异度/多样性全压低 | 跨镜不一致 |
| 空间站位 + 机位（Plate-A/B/C/D）锁定 | 分镜对不上 |
| ASCII 俯视图 + 轴线规则 | 越轴、空间错乱 |
| 道具连续性表追踪每状态跳变 | 道具凭空变形 |
| 「不得重建房间」重复声明 | 同一场景生成不同样 |
| 材质排他句（「不是大理石」）| 静物被生成成石头 |
| 「无人物、无人手」 | 静物图多出手 |
| 配音指令四段式 | 角色声音跨镜不一致 |
| 镜头时长按情绪权重分配 | 节奏平均无层次 |
| 版本修正记录 | 同一个坑反复踩 |
| 废片归档 + 标注原因 | 不知道什么方案行不通 |
