# 《反话》剧本（节选：场 1–2）

> 完整剧本 404 行、约 10 分钟。此处节选前两场，用于展示**剧本格式规范**。

## 立项锚定

- **核心赛道**：都市日常 / 言情（奇幻外壳：灵魂相伴）
- **一句话故事**：一个从小只会说"反话"的男孩，遇到世上唯一能听懂他的女孩；他为救她车祸离世后，她用一辈子对着空气替他说话——却不知道他的灵魂始终在身旁，而她猜的每一句，都一字不差。
- **核心立意**：真正的懂得不需要声音。爱一个人，就是成为他的翻译。
- **主结构原型**：身份/关系错位揭底（表层"人鬼相守" → 一翻"她看不见他" → 二翻"他真的在，她句句猜中" → 终翻"死后重逢，第一次亲耳听见"）
- **视觉形态**：AI 真人写实电影短片，胶片颗粒质感
- **成片形态**：闭环短片
- **画幅**：16:9 横屏
- **预估时长**：约 10 分钟（以故事节奏为准，不锁死）
- **固定规范**：全片无字幕、无配乐 BGM，仅保留真实环境音；时空跳转用黑底白字卡；所有台词由视频生成模型直接生成，禁用 TTS。

## 人物设定

- **陈默**（男：7 岁 → 24 岁；灵魂永驻 24 岁）：清瘦，黑碎发，单眼皮，五官清秀，常穿米白/燕麦色针织衫、白衬衫。自幼表达错位——**心里越软，出口越硬；动作永远比语言诚实**。24 岁因车祸离世，灵魂留在江晓身边，容貌不再变化。
- **江晓**（女：7 岁 → 终老）：黑中长发（晚年银白），鹅蛋脸，卧蚕明显，笑起来温婉；表面柔软，内核坚韧。全世界唯一能"翻译"陈默的人。
- **陈默母亲**：钟点工模样，蓝布外套，双手粗糙，常年疲惫。
- **护士**（次要角色，无参考图，纯文字描述）：三十岁上下，浅色护士服，动作轻。

## 签名道具

- **白色绘图橡皮**——"他写错的字，她来擦"。
- **旧铁皮盒**——装陈默几十年里送的橡皮。

## 场1　日 / 内　陈默家（老旧筒子楼）

**人物**：小陈默（7 岁）、母亲
**站位**：母亲在画面深处门口；小陈默在画面中央矮凳上，后走到母亲面前。

【画面1】
▲ 全景转中景，午后，屋内昏黄。小陈默趴在小板凳上看一本翻卷了边的儿童读物，轻声念。

陈默（念）："书上说……人一直干活，就会变老；变老了，就会死。"

【画面2】
▲ 近景。门开，母亲拎着菜进来，另一只手捶着后腰，鬓角汗湿。她坐下脱鞋，手抖着揉脚踝。小陈默看着她，脸一点点绷紧。

【画面3】
▲ 特写。小陈默爬下凳子，走到母亲面前，攥着衣角，憋红了脸。

陈默（小声）："妈……"
母亲（累得笑）："饿了？妈这就做饭。"

【画面4】
▲ 特写，他很想说出"妈妈你别老，我害怕"——

陈默（脱口而出）："你要死了。"

【画面5】
▲ 特写：母亲的笑僵在脸上。静。

母亲（声音发颤）："……谁教你这么说的？"
陈默（越急越糟）："书上说的……你天天干活，你就要死了。"

【画面6】
▲ 中景。母亲眼圈红了，别过脸用袖口擦眼睛，起身往厨房走，背影佝偻。

母亲："妈死不了。"

【画面7】
▲ 近景。小陈默愣在原地，手伸到一半，转而死死捂住自己的嘴。他倒了一杯水，端到厨房门口，递过去。

陈默："你喝……死得慢点。"

【画面8】
▲ 特写：母亲背对着他，肩膀发抖，眼泪掉进洗菜盆。小陈默一只手捂着嘴，另一只手端着水杯悬在半空，杯口冒着热气。

【音效】板凳挪动、钥匙、远处邻里说话、水龙头、水杯轻磕。

## 场2　日 / 内　小学教室

**人物**：小陈默、小江晓、同学若干
**站位**：陈默靠窗，在画面左侧；江晓坐他右侧邻座。

【画面1】
▲ 中景，午后阳光斜进教室，铅笔沙沙。小江晓翻铅笔盒，找不到橡皮，作业本上写错一处，急得咬唇。她侧身戳陈默的胳膊。

江晓（小声）："陈默，橡皮借我用一下，行吗？"

【画面2】
▲ 近景。陈默一愣，抓起自己那块用掉一半的白橡皮，手忙脚乱推过课桌交界——橡皮落在她作业本上，他脸涨得通红。

陈默："你妈没给你准备橡皮吗？"

【画面3】
▲ 中景。周围同学转头。

同学甲（低声）："他怎么这么说话啊。"
江晓（愣住）。

【画面4】
▲ 特写（江晓视角）：本子上的橡皮；陈默红透的耳朵；他悬在半空的手，手指朝橡皮又推了推。

【画面5】
▲ 近景。

江晓（拿起橡皮，轻声）："谢谢。"
陈默（猛地抬头，像没听清）。

## 剧本格式规范

这份剧本的格式是**给 AI 视频生成模型直接消费**的，因此有几个严格要求：

**① 每场开头必须有三行头**

```
## 场N　日/夜 / 内/外　地点
**人物**：列出本场出场角色
**站位**：写明每个人的画面位置
```

「站位」这一行是关键——它直接对应资产包里的机位锁定。
没有站位，AI 生成时人物位置会乱。

**② 画面与台词严格分离**

```
【画面N】
▲ 景别 + 运镜 + 内容描述

角色（表演提示）："台词"
```

- `▲` 后面是画面提示，标明景别（全景/中景/近景/特写）
- 台词单独一行，括号里是**表演提示**而非说明

**③ 音效单独标注**

```
【音效】板凳挪动、钥匙、远处邻里说话、水龙头、水杯轻磕
```

列出这一场需要的环境音。成片规范要求「真实环境音写足保留」，
所以音效要在剧本阶段就列清楚，不能等到后期再补。

**④ 特写要标注视角**

```
【画面4】
▲ 特写（江晓视角）：本子上的橡皮；陈默红透的耳朵……
```

同一部戏里的特写可能来自不同角色的视角，
必须标注，否则 AI 会把两个视角混在一起。

**⑤ 括号里的表演提示要写情绪而非动作**

```
母亲（累得笑）："饿了？妈这就做饭。"
陈默（越急越糟）："书上说的……你都要死了。"
```

「累得笑」「越急越糟」——这些是给配音/表演模型的
情绪提示，比「她很累地笑」更有效。

**⑥ 留白也是设计**

场 1 画面 5 只写「母亲的笑僵在脸上。静。」
一个字的情绪描写都不加。

这种留白在 AI 生成时反而更稳定——
写得太细（「笑容凝固、眼眶泛红、嘴角下垂」）
模型往往会过度演绎。
