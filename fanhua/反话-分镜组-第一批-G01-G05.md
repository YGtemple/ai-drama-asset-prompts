## 这份分镜组的方法论

### ① `_::~OUTPUT_START::~_` / `_::~FIELD::~_` 两段式

每个分镜组由两段组成：

- **`_::~OUTPUT_START::~_` 到 `_::~FIELD::~_`**：**输入头**
  场景引用（首位不 @）、角色 @编号、物品 @编号
- **`_::~FIELD::~_` 之后**：**渲染正文**
  场景重声明（强调「不得重建房间」）、角色位置、逐镜描述

分成两段的意义：**输入头是结构化的引用清单，正文是自然语言描述**。
AI 消费时先读引用建立素材绑定，再读正文生成画面。

### ② 摄影参数写在每一镜里

```
镜头1：6s 全景转中景，平视，32mm，轻推。
镜头3：6s 中景，侧逆光，35mm，固定。
镜头4：3s 特写，俯拍本面，85mm/微距，固定。
```

四个参数齐全：**时长 · 景别 · 机位角度 · 焦段 + 运镜**。

焦段选择有明确意图：
- 32mm 全景——交代空间
- 50mm 近景——人物互动
- 85mm 特写——情绪放大

### ③ 配音指令的四段式结构

```
【配音指令：陈默7｜稚嫩童声脆｜状态（念书/似懂非懂）
  ｜语气特点（小音量/语速慢/一字一顿）：书上说……】
```

拆成四段：
- **音色标识**：陈默7（角色+年龄）
- **音色特征**：稚嫩童声脆
- **情绪状态**：念书/似懂非懂
- **语气参数**：小音量 / 语速慢 / 一字一顿

这个结构让同一个角色在不同情绪下保持音色统一，
同时让情绪变化可控。对比同一批里的几镜：

```
陈默7｜稚嫩童声脆｜状态（念书/似懂非懂）｜语气特点（小音量/语速慢/一字一顿）
陈默7｜稚嫩童声｜状态（害怕/冲口）｜语气特点（大音量/语速快/尾音硬）
陈默7｜稚嫩童声｜状态（嘴硬/手忙脚乱/肯借）｜语气特点（大音量/语速快/尾音硬得像质问）
```

音色特征字段不变（「稚嫩童声」），状态与语气参数变。
这正是跨镜头角色声音一致的技术手段。

### ④ 镜头时长按情绪分配

G03 的 7 个镜头：4/4/3/3/3/5/4 秒 ＝ 26 秒

- 情绪平淡的镜头（同学转头、拿橡皮）给 3 秒
- 情绪关键镜（江晓替他正名）给 5 秒
- 对白多的镜头（陈默嘴硬）给 4 秒

**镜头时长不是均分的**，按情绪权重分配。

### ⑤ 承接写在组尾

```
衔接（至下一组）：硬切连贯——同场景，
他憋到极致→冲口而出，不加片。
```

明确告诉下一组从哪接、用什么转场（硬切）、
衔接点在哪（情绪爆发瞬间）。

### ⑥ 「不得重建房间」写进正文

```
场景：陈默家（背景、机位、门窗、挂钟严格不变，
不得重建房间，仅人物动作变化）
```

这条约束在每个分镜组里重复出现。
AI 生成时如果不强调，会把同一个房间生成成不同样子——
挂钟位置变了、窗户数量变了。
