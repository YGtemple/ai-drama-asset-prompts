# 《国家的孩子》剧本 v1 → v2 演进对照

> 展示同一个 AI 复刻短剧项目的两版剧本，说明从「自编版」到「原片台词版」的迭代方向。

## v1 · 自编版

- **核心赛道**：开放赛道（年代历史/真实事件/催泪群像）
- **一句话故事**：1960年粮荒中，三千南方孤儿被送往草原、东北、陕北，被素不相识的牧民和百姓用命养大；65年后DNA寻亲，他们在"一半长江水一半蒙古风"中找到回家的路。
- **核心立意**：草原上的爱够多，就能养活孩子——这是一个民族对另一个民族的骨肉相托。
- **主角群像**：都贵玛（草原母亲）、鞍山养父（钢厂工人）、何腾（被领养的孤儿）
- **主结构原型**：多维视角塌缩（群像式，多条线最终收束于"团圆"一个情感点）
- **主叙事重心**：强剧情向（开局即困境——雪地里的襁褓）
- **视觉形态**：AI真人剧，暖棕低饱和胶片质感
- **成片形态**：闭环短片（3分30秒）

## v2 · 原片台词版

- **核心赛道**：年代历史 / 真实事件改编
- **一句话故事**：上世纪60年代粮荒，三千南方孤儿被送往草原、东北、陕北，被当地百姓用命养大；65年后DNA寻亲，骨肉团圆。
- **核心立意**：大爱无疆——草原给你命，江南给你生，谁也不是外人。
- **主角**：都贵玛（齐木格）、何腾、张凤仙、鞍山养父
- **主结构原型**：多线群像 × 时间跨度双时空（1960 / 2025）
- **主叙事重心**：强剧情向——以小见大，普通人的选择撑起宏大历史
- **视觉形态**：AI真人电影感，暖棕低饱和胶片质感
- **成片形态**：闭环短片（约5分30秒）
- **画幅**：横屏16:9
- **声音**：无BGM，台词全部写入画面提示词，不用TTS
- **字幕**：全片零字幕，仅时空跳转处黑底白字（如"1960年 冬""2025年"）

## 迭代方向的五个要点

### 1. 从「自编」到「原片台词」

v1 明确标注为「自编版」；v2 改为「原片台词版」——台词改为贴近真实纪录片的原始记录。

对 AI 复刻类项目，这是正确方向：**用真实史料的台词比自创台词更可信**，也更容易通过观众检验。

### 2. 时长从 3分30秒 拉到 5分30秒

v1 更紧凑，v2 加长。原因可推测：

- 原片台词版本需要更多时间承载真实内容
- 加长后能容纳更多群像角色（v2 主角从 3 人增到 4 人，多了「鞍山养父」）

### 3. 新增了四条硬规范

v2 比 v1 多了：

- **画幅**：横屏16:9
- **声音**：无BGM，台词全部写入画面提示词，不用TTS
- **字幕**：全片零字幕，仅时空跳转处黑底白字
- **主角姓名校正**：都贵玛 → 齐木格

「不用 TTS」这一条尤其关键——AI 视频生成模型自己发声，
比 TTS 合成更自然，也避免了机械音。

### 4. 分镜精度大幅提升

v1 只有「人物设定表」，没有分镜。
v2 精确到每镜秒数、场景、人物、画面描述、台词：

```
### 镜头01（6秒）
**场景**：1960年冬，锡林郭勒草原，蒙古包外雪原
**人物**：无（环境空镜）
**画面**：大远景，茫茫白雪覆盖的草原，一眼望不到边……
**台词**：无
```

每镜 4-6 秒，是短视频生成模型稳定输出的时长区间。
这个「短镜头、快切」的节奏是刻意设计的。

### 5. 与资产层的接口保持一致

v2 的「横屏16:9」「无字幕」「暖棕低饱和胶片色调」
与资产包的全局视觉铁律完全对应。
剧本层和资产层的规范必须一致，否则两层会打架。

---

## 这个演进反映的工作方式

- **v1 先把故事讲清楚**（人物设定、赛道、结构原型）
- **v2 再把画面落实**（分镜秒数、场景、台词）
- **在 v2 阶段回头校正 v1 的事实错误**（都贵玛→齐木格）

这种「先粗后细 + 持续校正」的节奏，
比一次性追求完美更实际——AI 生成能力有限，
需要边做边调整规范。
